AtomJS documentation

Desktop apps.
Less runtime.

AtomJS is an alpha JavaScript framework for building lightweight cross-platform desktop applications with familiar Electron-style APIs and the operating system WebView.

View the project Read the docs

Install the alpha packages

npm install electron@npm:@atom-js-org/electron@alpha
npm install --save-dev @atom-js-org/cli@alpha

Use Electron-style APIs

const { app, BrowserWindow } = require('electron');

app.whenReady().then(() => {
  const win = new BrowserWindow({ width: 1000, height: 700 });
  win.loadFile('index.html');
});
System WebViewsWKWebView on macOS, WebView2 on Windows, and WebKitGTK on Linux.

Project status

AtomJS is an alpha foundation. It does not bundle Chromium and is not yet a production-complete implementation of every Electron API. Compatibility expands release by release while unsupported behavior remains explicit.

Source, issues, and contribution details are available on GitHub.
