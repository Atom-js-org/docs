## Output formats

A Linux build can produce:

- standalone application binary
- portable `.tar.gz`
- `.AppDir`
- `.AppImage`
- Debian `.deb`
- RPM `.rpm`

## Tool availability

- AppImage output requires `appimagetool`.
- RPM output requires `rpmbuild`.
- AtomJS can assemble the Debian archive directly.

Package on a matching Linux environment and test each artifact on the target distribution family.
